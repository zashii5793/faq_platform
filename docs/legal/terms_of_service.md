## 第1条（適用）

本利用規約（以下「本規約」）は、[屋号または法人名]（以下「当方」）が提供する社内 FAQ 検索プラットフォーム「Inquira」（以下「本サービス」）の利用条件を定めるものです。本サービスを利用する法人（以下「契約者」）は、本規約に同意したものとみなします。

## 第2条（利用契約の成立）

1. 契約者が当方所定の方法（Stripe Payment Link での決済、または書面による契約締結）により申し込み、当方がこれを承諾した時点で利用契約が成立します。
2. 当方は、以下のいずれかに該当する場合、申込を承諾しないことができます。
   - 反社会的勢力に該当する、またはその関係者と判断される場合
   - 過去に本規約違反を理由として契約を解除されたことがある場合
   - その他、当方が不適当と判断する事由がある場合

## 第3条（プランと料金）

1. 本サービスの利用料金は別途定める「[料金表](https://inquira.example.com/pricing)」に従います。
2. 利用料金は前払いとし、Stripe 等の決済代行サービスを通じてクレジットカード決済または銀行振込により支払うものとします。
3. 月額プランは自動更新とし、解約申出のない限り毎月の契約日に翌月分の利用料金が請求されます。
4. 消費税は別途とし、適格請求書発行事業者として登録番号 [T-XXXXXXXXXXXXX] により対応します（取得済みの場合）。

## 第4条（提供範囲）

本サービスは契約プランに応じて以下の機能を提供します（詳細はプラン表参照）：

- ドキュメント取り込み（PDF / Word / Excel / Markdown 等）
- 自然言語による質問応答（RAG + Anthropic Claude API 経由）
- PII（個人情報）自動マスキング機能
- 監査ログ機能
- 文書メンテナンス機能（追加・削除）
- Google Workspace SSO 認証

## 第5条（利用環境）

1. 本サービスは契約者の自社環境（オンプレミスまたは契約者が指定するクラウド）に当方がデプロイする方式を基本とします。
2. 別途合意した場合、当方が運用するマネージドクラウド環境上で提供することができます。
3. 契約者は、本サービスの稼働に必要な以下を自己の責任で準備・維持するものとします。
   - サーバ／VM またはクラウド契約（CPU 2vCPU 以上、メモリ 4GB 以上を推奨）
   - HTTPS 通信用のドメイン・SSL 証明書
   - Google Workspace 等の認証基盤
   - Anthropic API キー（または当方契約のキーを共用する場合は別途定める利用上限）

## 第6条（データの取り扱い）

1. 契約者が本サービスに投入したドキュメントおよび質問履歴（以下「契約者データ」）の所有権は契約者に帰属します。
2. 当方は契約者データを以下の目的でのみ利用します。
   - 本サービスの提供
   - 契約者からの要請に応じた障害対応
3. 当方は契約者の事前同意なく、契約者データを第三者に開示しません。ただし、法令に基づく場合を除きます。
4. 本サービスは Anthropic Claude API を利用するため、検索結果として LLM に送信される文書チャンクは Anthropic 社のサーバを経由します。当方は Anthropic 社と Zero Data Retention（ZDR）契約またはそれに準ずる条件を交渉する努力義務を負いますが、これを保証するものではありません。
5. 詳細は別途「[プライバシーポリシー](https://inquira.example.com/legal/privacy)」に従います。

## 第7条（禁止事項）

契約者は本サービスの利用にあたり、以下の行為をしてはなりません。

- 法令または公序良俗に違反する行為
- 第三者の知的財産権、プライバシー権、名誉権、その他の権利を侵害する行為
- 本サービスのリバースエンジニアリング、改変、再配布
- 本サービスを利用した第三者向けの SaaS 提供（再販）
- 不正アクセス、過剰なリクエスト等、本サービスの運営を妨害する行為
- 当方の事前承諾なく、ベンチマーク結果や脆弱性情報を公開する行為

## 第8条（提供の中断・停止）

1. 当方は以下の場合、契約者への事前通知なく本サービスの全部または一部の提供を中断することができます。
   - 保守・メンテナンス（事前通知が可能な場合は7日前までに通知）
   - 天災・戦争・通信障害等の不可抗力
   - Anthropic API の障害・仕様変更
   - その他、当方がやむを得ないと判断する事由
2. 提供中断による損害について、当方は故意または重過失がある場合を除き責任を負いません。

## 第9条（解約）

1. 契約者は、解約希望月の前月末日までに当方所定の方法で通知することにより、利用契約を解約することができます。
2. 解約後、契約者データは [解約から60日後] に当方の管理下から削除されます。希望する場合、削除前にエクスポート可能です。
3. 既に支払われた利用料金は、当方の責に帰すべき事由による場合を除き、返金しません。

## 第10条（保証の制限）

1. 本サービスは「現状有姿」で提供され、当方は本サービスが契約者の特定の目的に適合すること、エラーなく稼働すること、特定の精度で動作することを保証しません。
2. 本サービスは AI を利用した検索・回答機能を含み、回答内容に誤りが含まれる可能性があります。契約者は重要な判断にあたっては本サービスの回答のみに依拠せず、必ず原文書または有資格者の判断を確認するものとします。

## 第11条（責任の制限）

当方が契約者に対して負う損害賠償責任は、当方の故意または重過失による場合を除き、当該損害発生時から遡って 12ヶ月間に契約者が当方に支払った利用料金の総額を上限とします。

## 第12条（規約の変更）

1. 当方は、必要に応じて本規約を変更することができます。
2. 重要な変更については、施行日の 30日前までに本サービス上または契約者の登録メールアドレスへの通知により告知します。
3. 通知後、契約者が本サービスの利用を継続した場合、変更後の規約に同意したものとみなします。

## 第13条（準拠法および管轄）

1. 本規約は日本法に準拠します。
2. 本サービスに関連する一切の紛争については、[東京地方裁判所] を第一審の専属的合意管轄裁判所とします。
