## はじめに

[屋号または法人名]（以下「当方」）は、社内 FAQ 検索プラットフォーム「Inquira」（以下「本サービス」）の提供にあたり、お客様の個人情報および機密情報を適切に取り扱うことを最重要事項として位置づけています。本ポリシーは、当方が取得・利用する情報の種類とその管理方法を明らかにするものです。

## 1. 取得する情報

### 1.1 契約者（法人）から取得する情報

| 区分 | 具体例 | 取得方法 |
|---|---|---|
| 契約者情報 | 法人名・所在地・担当者氏名・連絡先メール・電話番号 | Stripe Payment Link または契約書 |
| 決済情報 | クレジットカード情報 | Stripe を経由（当方は番号を保持しない） |
| 利用情報 | ログイン履歴・質問履歴・操作ログ | 本サービスの監査ログ機能 |
| 投入ドキュメント | 契約者が取り込んだ社内文書 | 契約者の自主投入 |

### 1.2 エンドユーザー（契約者の従業員）から取得する情報

| 区分 | 具体例 | 取得方法 |
|---|---|---|
| 認証情報 | Google アカウントのメールアドレス・氏名 | Google OAuth |
| 質問内容 | エンドユーザーが本サービスに入力した質問 | 本サービス利用時 |
| フィードバック | 👍/👎 評価 | 本サービス利用時 |

### 1.3 自動的に収集する情報

- アクセスログ（IP アドレス・User-Agent・アクセス時刻）
- エラーログ（スタックトレース・操作内容）

## 2. 利用目的

取得した情報は、以下の目的でのみ利用します。

1. 本サービスの提供・運営
2. 契約者からの問い合わせ・障害対応
3. 利用料金の請求・領収書発行
4. 本サービスの品質改善（統計情報として匿名化したもののみ）
5. 重要なお知らせ（規約変更・障害通知等）の送付
6. 法令に基づく対応

## 3. 第三者提供

当方は、以下の場合を除き、取得した情報を第三者に提供しません。

- 契約者の事前同意がある場合
- 法令に基づく場合（裁判所・警察等の公的機関からの開示請求等）
- 人の生命・身体・財産の保護のために必要であって、本人の同意取得が困難な場合

## 5. 契約者データの取り扱い

### 5.1 LLM への送信

本サービスは Anthropic Claude API を利用するため、質問への回答生成にあたり以下のデータが Anthropic 社サーバへ送信されます。

- 質問本文（PII マスキング処理後）
- 検索でヒットしたドキュメントチャンクの内容（上位 5件）

当方は Anthropic 社との間で、送信データを Anthropic 社の機械学習モデル訓練に利用しないこと（**Zero Data Retention / オプトアウト**）を可能な限り確保する努力をします。ただし、Anthropic 社の方針変更等により完全な保証ができない場合があります。

### 5.2 オンプレミス／自社環境デプロイ

契約者の自社環境にデプロイした場合、契約者データは契約者の管理下にあり、当方のサーバを経由しません（Anthropic API 通信を除く）。

### 5.3 マネージドクラウド環境

当方が運用するマネージドクラウドに契約者データを保存する場合、暗号化（保存時 AES-256、通信時 TLS 1.2 以上）を施したうえで、契約者ごとに論理的に分離します。

## 6. 保存期間

| データ種類 | 保存期間 |
|---|---|
| 契約者情報 | 契約終了後 5年 |
| 決済情報 | Stripe 側の規定による |
| 利用情報（監査ログ） | 1年（オンプレ環境では契約者の任意） |
| 投入ドキュメント | 解約後 60日以内に削除 |
| エラーログ | 90日 |

## 7. セキュリティ対策

- 通信の暗号化（HTTPS / TLS 1.2 以上）
- 保存データの暗号化（AES-256、マネージド環境のみ）
- アクセス制御（Google OAuth + 許可ドメイン制限 + 監査ログ）
- 定期的なセキュリティアップデート
- バックアップの暗号化保管
- インシデント発生時の通知体制（覚知後 72時間以内）
