## note への掲載手順

### 1. 有料エリアの境界

本文中の以下の行が、無料 / 有料の境界。

```
<!-- ===== ここから有料エリア ===== -->
```

- **この行より上**（第 0 章「何が手に入るか」〜 第 1 章「何を作ったのか」）を無料公開範囲にする
- 無料部分に「買うべきでない人」を明記してあるのは意図的。高額商品では、
  期待外れによる低評価を防ぐことが、追加の 1 件を売ることより価値が高い

### 2. 記事の体裁 — **Markdown をそのまま貼ってはいけない**

note のエディタはリッチテキストであり、**Markdown 記法をそのまま解釈しない**。
特に **表組みは機能自体が存在しない**ため、原本をそのまま貼ると表が崩れて読めなくなる。

そのため、貼り付けには `note_01_for_note_paste.md` を使う。

| 記法 | note での扱い | 変換後 |
|---|---|---|
| 表 `\| a \| b \|` | **非対応**（機能なし） | 箇条書き（`■ 見出し` + `・列名：値`） |
| 見出し `## x` | `#` が文字として残る | `【x】` / `◆ x` に変換 → 貼付後に見出しスタイルを適用 |
| コードブロック | 貼付後に「コード」スタイルを適用 | 変換せず維持（ASCII 構成図もここで保護される） |
| 箇条書き `- x` | 概ねそのまま使える | 変換不要 |
| 太字 `**x**` | `*` が文字として残る | **貼付後に手動で太字指定**（下記参照） |

> ⚠ `**太字**` の `*` は残る。全文の太字を手で直すのは非現実的なので、
> **見出し直後の要点だけ手で太字にし、残りは `*` を一括削除する**のが現実的。
> エディタの置換、または `sed 's/\*\*//g'` で消せる。

#### 原本を編集したときの再生成

```bash
python3 docs/note/assets/to_note.py \
  docs/note/note_01_faq_tool_with_claude_code.md \
  docs/note/note_01_for_note_paste.md
```

変換スクリプトはコードブロックの中身を一切変更しない（入れ子フェンス ` ```` ` にも対応済み）。

#### 表を「画像」で載せたい場合

読みやすさを優先するなら、主要な表だけ HTML → PNG にして画像で貼る手もある。
その場合は `assets/skills/ja-pdf-export/SKILL.md` のフォント指定をそのまま使うこと
（指定しないと中国語書体で描画される）。ただし画像内の文字は検索・コピーができないため、
**全部を画像にするのは避ける**。箇条書きを基本に、比較表だけ画像が現実的。

### 3. テンプレートの配布方法（3 案）

| 方式 | 手順 | 向き |
|---|---|---|
| **A. 記事内に全文掲載**（推奨・実装済み） | 付録 A〜F をそのまま本文に含める | 追加作業ゼロ。購入者はコピペで使える |
| B. ZIP ダウンロード | `assets/` を ZIP 化し、有料エリアにリンクを置く | ファイル構造ごと渡したい場合 |
| C. 限定リポジトリ招待 | 購入者に GitHub の private リポジトリへ招待 | 継続更新を提供する場合 |

> A を採用しても、B を「おまけ」として併記すると体感価値が上がる。
> B のリンクは**有料エリア内**に置くこと。

## 価格設定についてのメモ

¥24,800 は、note の有料記事としては最上位帯（一般的な技術記事は ¥500〜¥3,000）。
この価格で成立させるには、**「記事」ではなく「テンプレート製品 + 導入知見」として売る**必要がある。
本記事はその前提で構成してある。

### 価格を支えている要素

| 要素 | 内容 |
|---|---|
| 再利用可能な資産 | テンプレート 9 点（CLAUDE.md / Skill 3 / プロンプト 12 型 / チェックリスト 3） |
| 検証可能な実数値 | コード 6,814 行・テスト 377 本・検索 5ms・API 1 質問 2〜3 円 |
| 設計判断の開示 | 「捨てた技術 4 つ」とその理由、ハルシネーション三重防御の実コード・しきい値・システムプロンプト全文 |
| 失敗の全件開示 | オンプレ導入の詰まり 13 件、アンチパターン 5 件、自分の技術的負債（main.py 4,471 行）も明記 |
| 再現手順 | 30 日スケジュール（日割り） |
| 対象読者の限定 | 「買うべきでない人」を先に明示 |

### 検討事項

- **販売初期は割引で実績を作る方法もある**
  （例: 先着 10 名 ¥9,800 →以降 ¥24,800。note は価格変更が可能）
- **記事②以降とのセット販売**（マガジン機能）で単価を正当化する構成も取れる
- 高額帯では「購入者限定の質問対応」を 1 回付けると、価格への納得感が大きく変わる
  （付ける場合は、対応範囲と期限を記事内に明記すること）
