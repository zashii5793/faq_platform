# AI 生成物 公開前チェックリスト

対象: 顧客に渡す資料、社外公開する記事・スライド、公開リポジトリ

> **この工程は省略できない。** 実際にここで実名混入を検出している。

## 1. 固有名詞（最優先）

- [ ] **個人の実名**が含まれていないか
      → AI は会話の文脈から親しみを込めて実名を書くことがある
- [ ] 顧客の正式名称・略称が含まれていないか
- [ ] 顧客の社内ドメイン、サーバー名、共有フォルダのパスが含まれていないか
- [ ] 内部 IP アドレスが含まれていないか

## 2. 事実確認

- [ ] 数値に **測定日または出典** が明記されているか
      → AI は生成時点の記憶で数値を書く。古い可能性がある
- [ ] 「〜と言われています」のような**根拠不明の断定**がないか
- [ ] 外部サービスの料金・仕様を書いている場合、**現時点で正しいか確認したか**

## 3. 表現

- [ ] 顧客の組織構造を決めつける表現がないか
      （例: 「情シスに聞いてください」「担当部署にご確認を」）
- [ ] 特定組織を指す表現がないか（「弊社」「A 社」）
      → テンプレートとして再利用できなくなる
- [ ] 読者の前提知識に対して、専門用語が適切か
      （全社員向け資料に「OAuth」「RAG」が出ていないか）

## 4. 体裁

- [ ] PDF の場合、**漢字が日本語書体か**（中国語書体になっていないか）
      → 『直』『経』『値』『骨』の字形で判別しやすい
- [ ] A4 に収まっているか、表が途中で切れていないか
- [ ] リンクが実際に開くか

## 5. 最終確認

- [ ] **これを見知らぬ第三者が読んだとき、誰の・どの会社の話か特定できないか**
