## 提供側メモ：この項目が抜けると何が起きるか

| 未確認項目 | 実際に起きた事故 |
|---|---|
| Docker 可否 | Docker 前提で全て準備 → 直前に不可と判明し作り直し |
| OS | Linux 用 install.sh を Windows Server に渡そうとした |
| 管理者権限 | タスクスケジューラ登録不可 → 自動起動方式の再設計 |
| DNS 権限 | 担当者と AD 管理者が別人 → 依頼書がなく数日停止 |
| FQDN 割当 | IP アドレスでは Google OAuth が通らず、公開できない |
| ファイル転送経路 | RDP 制限で ZIP を直接渡せず、配布方式を変更 |
