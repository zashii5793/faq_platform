📌 戦略の整理
プロダクトは 「機能としては完成」、「実運用での検証段階」。新規開発より 「A社で実際に動かして事例化」 が最優先。

🚀 次にやるべきこと（優先順）

  1. 自分のMacで一度フル動作確認 — ./scripts/demo.sh でデモモード起動して、機能を実体験する
  2. A社向け公開URL構築 — inquira-ai.com 購入 → Cloudflare Tunnel 設定（既存ガイドあり）
  3. A社ユーザリスト取得 — 試験参加者のGoogleアカウント収集
  4. A社のチケットデータ取り込みPoC — 1,000件中、上位2〜3割（パレート原則）でFAQ化
  5. 2週間試験運用 → フィードバック収集 — Phase 2 / 3 の優先順位を実データから決定
  6. 事例化コンテンツ作成 — 営業用の導入事例ページ・動画
