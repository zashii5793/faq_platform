🏗️ 構築したシステムの構成

A社ユーザ（ブラウザ）
    ↓ HTTPS
https://faq.inquira-ai.com
    ↓ Cloudflare CDN + SSL（自動）
Cloudflare Tunnel（inquira-trial）
    ↓ 暗号化トンネル経由
Mac（石澤さん）http://localhost:8000
    ↓
Inquira アプリ（Python/FastAPI）
    ↓ Google OAuth 認証
Claude AI（Anthropic API）で回答生成

🔐 セキュリティの仕組み

層仕組み効果
通信の暗号化 Cloudflare が自動で HTTPS/SSL を提供 通信内容の盗聴防止
認証 Google OAuth — Googleアカウントでのみログイン可 なりすまし防止
認可 ALLOWED_EMAILS に登録したメールのみアクセス可 部外者のアクセス遮断
ポート公開なし Mac のポートを直接インターネットに開けていない（Tunnel経由） 不正アクセスリスク最小化
AIの学習利用なし Anthropic API — 入力データはAIの学習に使われない 社内情報の外部漏洩防止

👥 A社ユーザを追加する手順

A社からユーザリストが届いたら、以下の手順で設定します（所要5分）
1 Google Test users に追加

👉 https://console.cloud.google.com/auth/audience?project=inquiretrial

  1. Test users セクション → + ADD USERS
  2. A社のメールアドレスを入力（改行区切りで複数追加可）:
tanaka@aaa-corp.co.jp
suzuki@aaa-corp.co.jp
yamada@aaa-corp.co.jp

3. SAVE をクリック

2 .env の ALLOWED_EMAILS に追加

Mac のターミナルで:

open -e ~/faq_platform/.env

ALLOWED_EMAILS= の行を編集（カンマ区切りで追加）:

ALLOWED_EMAILS=hideki.ishizashi@gmail.com,tanaka@aaa-corp.co.jp,suzuki@aaa-corp.co.jp

保存（Cmd+S）

3 アプリを再起動

serve.sh を起動しているターミナルで:

Ctrl+C
PYTHON=python3.11 ./scripts/serve.sh

⚠️ Tunnel（cloudflared）は再起動不要、そのままでOK

🔄 毎日の起動・停止手順

▶ 朝: 起動する時

ターミナルを2つ開いて順番に実行:

① アプリ起動（ターミナル1）

cd ~/faq_platform
PYTHON=python3.11 ./scripts/serve.sh

② Tunnel 起動（ターミナル2）

cloudflared tunnel run inquira-trial

→ 両方起動したら https://faq.inquira-ai.com にアクセスしてログイン確認

⏹ 夜: 停止する時

両方のターミナルで Ctrl+C を押す。それだけでOK。

データは Mac の ~/faq_platform/data/ に保存されているので消えません。

💡 Mac のスリープ防止（推奨設定）

稼働中に Mac がスリープするとアクセス不可になります。以下のいずれかで防止:

方法A: ターミナルコマンド（起動中だけ有効）

caffeinate -d -i &

方法B: システム設定（恒久設定）

「システム設定」→「ロック画面」→「スクリーンセーバー開始とディスプレイオフ」を「なし」に変更
