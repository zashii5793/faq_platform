# Inquira 新規顧客獲得プレイブック（最初の1社を取りに行く）

> 想定読者: ZAXEL 営業担当（zashii）
> 利用シーン: タカヤ・教育系A社様以外の **完全新規** プロスペクトを発掘し、
>           試験導入契約まで持ち込む
> 期間: リード発掘 〜 契約まで 2〜3ヶ月想定
> このドキュメントは [trial_implementation_guide.md](./trial_implementation_guide.md) の前段に位置する
> 「**そもそも誰に売るか・どう接触するか**」を扱う

## 0. なぜ「最初の1社」を急ぐべきか

| 状態 | 帰結 |
|---|---|
| 第3顧客がいる | 「複数社が使っている SaaS」と言える → 商談成約率↑ |
| 第3顧客がいない | 「タカヤ・教育系A社様だけ」→ 業界違いの顧客から不安視される |

→ **第3顧客の獲得が、第4・5顧客の口説きやすさを決める**。

## 1. ICP（理想の最初の新規顧客像）

### 1.1 業種別優先度

| 業種 | 優先度 | 理由 |
|---|---|---|
| **製造業（中堅）** | ★★★ | マニュアル多い・問い合わせ多い・IT予算あり |
| **士業（会計・社労士・行政書士事務所）** | ★★★ | 業務知識の集約ニーズ大、情報セキュリティ意識高い |
| **教育（既存と別業態）** | ★★ | Industry Pack 第2号化できる |
| **物流・建設** | ★★ | 現場業務でモバイル対応が刺さる |
| **SaaS ベンダー（自社製品サポートに）** | ★★ | 技術理解高くスムーズ・事例公開しやすい |
| **小売チェーン** | ★ | 店舗マニュアル統一ニーズ |
| **医療・金融** | × | コンプライアンスが重く第1号には不向き（3社目以降） |

### 1.2 規模条件

- 従業員 **30〜200 名**（少なすぎると ROI 出ない、多すぎると意思決定遅い）
- 売上 **5〜100億円**
- **情シス専任者がいる**（自走運用に必要）
- **Google Workspace 契約済み**（OAuth 認証の前提）

### 1.3 痛みポイント（あれば刺さる）

- 「情シス・総務に同じ質問が毎日来る」
- 「新人がオンボーディングで先輩の時間を奪う」
- 「ChatGPT を社員が個人利用していて困っている」
- 「マニュアルが Notion / Drive / メール / 紙に散在」
- 「退職時のナレッジ流出が怖い」

## 2. リード発掘の5チャネル

### Ch.1 既存ネットワーク（最優先・成約率最高）

**やること:**
1. zashii さんの LinkedIn / Facebook / Wantedly から、上記 ICP に該当する企業を洗い出し
2. 元同僚・取引先・大学/前職の先輩・後輩で **情シス / 総務 / 経営企画** を担当している人をリストアップ
3. 「最近こんなプロダクト作ってて、ヒアリングだけさせて欲しい」のソフト接触

**接触メッセージ例（LinkedIn DM）:**
```
ご無沙汰しております。○○です。

最近、社内ヘルプデスク AI のプロダクト「Inquira」を立ち上げ、
タカヤ様（自動車業）・教育系企業様で運用検証中です。

○○さんの会社では、社員からの「これってどうやるんでしたっけ？」系の
問い合わせ対応で工数を取られているような状況ありますか？

もしご関心あれば、20分ほどヒアリングのお時間いただけないでしょうか。
売り込みではなく、課題感の調査のためです（無料）。
```

→ **5名にDMして1〜2件ヒアリングが取れれば上出来**

---

### Ch.2 note / Zenn / Qiita 記事公開（インバウンド）

**やること:**
- 既に作成済みの [docs/blog_post.md](./blog_post.md) を3プラットフォームに公開
- LinkedIn で告知 + ハッシュタグ（#社内DX #ナレッジマネジメント #AI活用）
- 月1〜2本ペースで継続発信
- 記事末尾に「相談はこちら」CTA + Stripe Payment Link

**期待値:** 月 200〜500 PV → 月 1〜3件の問い合わせ

**重要:** 「Inquira の宣伝」ではなく「**社内 FAQ を AI で実装する技術解説**」として書く。営業色を抑えると拡散される。

---

### Ch.3 業界イベント・カンファレンス登壇

**やること:**
- 「**社内 DX**」「**ナレッジマネジメント**」系の勉強会・カンファレンスに登壇枠を取りに行く
- 例: HRカンファレンス / 情シス Slack コミュニティ / セキュリティイベント
- 15〜30分の発表枠で「タカヤ事例（匿名化）」を話す
- 質疑応答で名刺交換 → 後日ヒアリング

**コスト:** ¥0〜数万円
**期待値:** 1イベント登壇で 2〜5件の商談リード

---

### Ch.4 パートナー経由（システム会社・IT商社）

**やること:**
- 中堅企業に売っている **IT 商社 / 業務システム会社** にパートナー営業
- 彼らが既に顧客との関係を持っており、追加提案として Inquira を載せられる
- マージン **20〜30%** 還元の提案

**例:**
- 業務システム導入会社（弥生・OBC 系のパートナー）
- 人事 SaaS の販売代理店
- セキュリティベンダー（ZTNA・MDM 系の販売店）

**期待値:** パートナー獲得後、四半期2〜3件の商談紹介

---

### Ch.5 コールド営業（最終手段）

**やること:**
- 業界リスト（業界四季報・Wantedly・OpenWork）から ICP 抽出
- 情シス部長 / 総務マネージャ宛にメール送付
- 返信率は **1〜3%** が現実線

**コールドメールテンプレ:**
```
件名: 社内問い合わせ AI Inquira — 製造業様向けの試験導入のご相談

○○株式会社 情報システム部 ○○様

突然のご連絡失礼いたします。ZAXEL の山中と申します。

提供しております。同業界の方々から、特に下記の課題感を伺うことが多く、
○○様にもご関心あれば 20分ほどお時間いただけないかと考えご連絡しました。

  • 情シス・総務に同じ質問が日に何件も来て工数を取られる
  • 新人が「マニュアルどこにある？」で先輩の時間を奪う

既存マニュアル（PDF・Word・Excel）をそのまま取り込み、社員が自然言語で

   ○月○日（火）14:00-14:20
   ○月○日（木）10:00-10:20
   ○月○日（金）15:00-15:20

弊社製品概要: https://[公開URL] （または資料を添付）

何卒よろしくお願いいたします。
ZAXEL 山中 ___@example.com
```

**期待値:** 100通送って 1〜3件商談 = 月 1〜2件のリード

## 3. 初回ヒアリング（20〜30分）の進め方

### 3.1 アジェンダ

| 時間 | 内容 |
|---|---|
| 5分 | アイスブレイク + 「弊社の課題感を教えてください」 |
| 10分 | デモ（実機・タカヤ環境）— 「貴社用にカスタマイズすると…」と即時編集UI で見せる |
| 10分 | 価格・運用イメージの説明 |
| 5分 | 次のステップ提案（14日 PoC か、検討期間か） |

### 3.2 必ず聞く質問（ディスカバリー）

```
1. 社員数は？ 部門構成は？
2. 現在、社内の「問い合わせ対応」工数はどれくらい？
   （週○時間／月○件くらい？）
3. 既存マニュアルはどこに置いていますか？
   （Notion / Confluence / Drive / メール / 紙？）
4. 認証は Google Workspace か Microsoft365 か？
5. 機密データの取り扱いポリシーは？
   （クラウド NG / オンプレ必須 / どこまで OK？）
6. 意思決定者は？ 予算決裁ラインは？
7. 過去に同種ツール（チャットボット等）を導入した経験は？
   良かった点・課題は？
8. 14日無料 PoC を試すなら、誰が運用しますか？
```

### 3.3 デモで見せる「3つの瞬間」

1. **質問→出典付き回答**（基本機能の信頼感）
2. **「該当情報なし」→ FAQ追加リクエストボタン**（運用しやすさ）
3. **組織情報を即時編集**（「貴社用にカスタマイズしますね」と現場でやって見せる）

## 4. リード優先度評価（Go/No-Go 判定）

ヒアリング後に下記でスコアリング:

| 観点 | +2点 | +1点 | 0点 |
|---|---|---|---|
| 業種マッチ | 製造・士業・教育 | SaaS・物流 | 医療・金融 |
| 規模 | 50〜200名 | 30-50 or 200-500名 | 30名未満 or 500名超 |
| 痛み | 「すぐ何とかしたい」 | 「興味あり」 | 「情報収集」 |
| 認証 | Google Workspace | Microsoft365 | その他 |
| 予算決裁 | ヒアリング相手が決裁可 | 上長承認で取れる | 不透明 |
| データ要件 | クラウドOK | オンプレ希望 | 規制業種 |
| 競合状況 | 比較対象なし | 1〜2製品検討中 | 既に他製品契約中 |

**判定:**
- **10点以上** → PoC打診（試験導入マニュアルへ進む）
- **6〜9点** → 二次商談で情報追加収集
- **5点以下** → メルマガリスト追加・優先度低

## 6. よくある反論と返答

### Q1: 「ChatGPT で良くないですか？」

> 「個人でお使いいただく分には便利ですが、業務利用には3つ問題があります。
>  ①社内文書を入れると Anthropic / OpenAI 側に学習リスク
>  ②回答に出典が出ないので、社員が確認できない
>  ③知らない領域も推測で答えてしまう（ハルシネーション）
>  Inquira は『**御社の文書だけ**を根拠に』『**出典付き**で』『**わからない時はそう答える**』設計です」

### Q2: 「精度はどれくらい？」

> 「タカヤ様での実測では、関連質問の正解率 71%（軽量版）です。
>  Embedding 切替で 85〜90% まで上がる設計です。
>  そもそも『うろ覚えで間違える』のではなく『わからない時はわからない』と返す設計なので、
>  間違った回答で混乱する事故はゼロです」

### Q3: 「月10万は高い」

> 「Standard プラン ¥3万からございます。30名規模ならまず Standard で十分です。
>  ROI 試算では、ヘルプデスク工数削減だけで月7.5万円相当の効果が出ますので、
>  Standard なら3〜4倍のリターンになります」

### Q4: 「うちはオンプレじゃないと無理」

> 「On-Premise プランで対応可能です。御社サーバに常駐インストールしますので
>  データは一切外部に出ません（Claude API 呼び出し以外）。
>  ZDR オプションで API 通信も学習されません」

### Q5: 「導入後の運用は誰がやるんですか？」

> 「情シスご担当者1名で運用可能な設計です。週30分ほどの作業で、
>  ナレッジ追加・削除・利用状況確認ができます。詳しい運用ガイドも
>  ご提供します（setup_for_admin.md）」

### Q6: 「セキュリティ評価が必要なんですが」

> 「セキュリティチェックリスト・データフロー図・監査ログ仕様を
>  別途お渡しします。ISO27001 取得済みの Anthropic 契約・
>  Google Workspace 認証・PII自動マスキング・JSONL監査ログまで
>  3層で対応しています」
