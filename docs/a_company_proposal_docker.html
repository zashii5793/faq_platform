2. Inquira とは

Inquira（インクワイラ）は、御社の既存ドキュメントを根拠に AI が回答する 社内ヘルプデスク向けのセルフサービス FAQ プラットフォームです。
Docker コンテナで配布しているため、御社サーバー上で完結します。

3. 主な機能

  • 多形式ファイル取り込み：PDF / Word / Excel / PowerPoint / Markdown / テキスト / HTML / CSV の 8 形式に対応
  • 出典付き回答：どの文書のどの部分を根拠にしたかを必ず提示。確信度も表示
  • ナレッジ蓄積：解決した質問を回答者がその場で共有 → 他社員もすぐ参照可能
  • 重複質問サジェスト：入力中に「似た質問が既にあります」をリアルタイム表示
  • 業界別マスキング：一般 / 教育 / 医療 / 金融の各業界に応じた個人情報マスキング
  • Google Workspace SSO：御社の Google アカウントでログイン。許可ドメイン/メールで制御
  • 監査ログ：質問・操作の全履歴を JSONL で日次保存。法令保全に対応
  • 管理画面：ドキュメント追加・削除、利用状況分析、改善要望対応、エクスポート

4. 導入後の利用イメージ

利用シーン

新人社員が「経費精算の領収書はいつまでに提出？」と質問 → AI が経費規程から回答 + 出典として規程の該当ページを提示。
回答に不足があれば 👎 を押して改善要望を投げる → 管理者が文書を補足取り込み → 再質問で改善された回答が返る。

5. システム構成とデータの安全性

Inquira は 御社サーバー内で完結する Docker コンテナ として提供されます。 データの実体はすべて御社サーバー内のディスクに置かれ、弊社（提供元）は 通常運用ではこのサーバーへのアクセス権を持ちません。

構成図

[ 御社サーバー / VPS or オンプレ Linux ] │ ├ Inquira コンテナ (Docker) ├ Caddy コンテナ (HTTPS 終端 / Let's Encrypt 自動更新) │ └ /srv/inquira/data/ # データ実体・御社情シスのみアクセス可 ├ faq_master/ # 取り込み済み文書 ├ audit/ # 監査ログ (法令保全) ├ org_settings.json └ ... ▲ │ 唯一の外部通信: │ Anthropic Claude API (マスキング済み質問のみ) ▼ [ 一般社員 ] https://inquira.<御社ドメイン>

データ主権の「3層担保」

① 物理層
データは 御社サーバーのディスク内 にしか存在しません。 弊社は通常運用で SSH 権限を持たないため、物理的にアクセスできません。
② UI 層
全画面の下部に 「データは貴社サーバー内 / 弊社からアクセス不可」 を常時表示。一般社員も常に確認できます。
③ 契約層
サポート時にサーバーアクセスが必要な場合は、御社情シスから 明示の許可と SSH 鍵の一時発行 が必要であることを契約に明記します。

7. 料金体系 — 3プランから選択

Anthropic API の 誰の財布で支払うか によって 3 つのプランをご用意しています。 御社の規模・運用方針に合わせてお選びいただけます。
推奨
A. 包括プラン
Inquira-managed / 月額固定
  • 月額固定費に API 利用料を含む
  • 「月◯◯問まで」の上限あり
  • 料金の予測可能性 ◎
  • 小〜中規模に最適
B. 実費連動プラン
弊社管理キー + 実費精算
  • 月額管理費 + API 実費
  • 使用量上限なし
  • 変動が大きい場合に最適
  • 月次で透明な使用状況レポート
C. BYO プラン
御社が Anthropic と直接契約
  • 月額管理費のみ
  • API 代は御社で直接支払い
  • Anthropic との直接契約要
  • 大規模・法務要件で選択
