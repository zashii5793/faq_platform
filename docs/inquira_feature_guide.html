IN-HOUSE AI HELPDESK

Inquira 機能ガイド

社内マニュアル・規程・FAQ を AI が読み、
社員の質問に出典付きで即答える。探す時間を、なくす。
WHY

こんな「探す時間」、ありませんか

「経費精算の締め切りっていつだっけ?」
「VPN がつながらない時の対処法、どこに書いてある?」
「有給は何日前までに申請?規程のどこ?」

毎回マニュアルを探し、人に聞き、回答を待つ — その積み重ねが、組織全体で膨大な工数になっています。 Inquira は、その質問に AI が即座に、根拠付きで答えます。

FEATURE

主な機能

💬 CHAT

1. 質問するだけ、出典付きで即回答

日本語で質問を入力するだけ。AI が社内ナレッジを検索し、根拠となるドキュメントを示しながら回答します。
  • 出典明示 — 「どのファイルの何ページを根拠にしたか」が必ず表示される
  • 関連度スコア — 参照した各ドキュメントの関連度を数値で確認できる
  • 会話継続 — 前の回答を踏まえた追加質問もできる
▲ 質問に対し、参照ドキュメントと確信度を添えて回答 (画面はデモデータ)
✓ TRUST

2. 確信度を色で表示 — 不確かな時は「答えない」

AI の「それっぽいけど間違った回答」を防ぐため、回答の確信度を 3 段階で明示。根拠が弱い時は無理に答えません。
確信度 83%・高い 社内ナレッジに明確な根拠あり。そのまま信頼してOK
確信度 69%・中程度 関連情報はあるが、出典を確認推奨
該当なし 根拠が無いので答えない。FAQ追加リクエストを促す
▲ 確信度バーと参照ドキュメントの関連度 (画面はデモデータ)
📊 ANALYTICS

3. 利用状況の統計分析ダッシュボード

「どれだけ使われ、どんな質問が多いか」を可視化。ナレッジ改善の判断材料になります。
  • 質問数の推移 — 日別・週別のグラフ
  • 回答率 — AI が答えられた質問の割合
  • 平均確信度 — 回答品質の指標
  • トップトピック — よく質問されるテーマ上位
  • 回答できなかった質問一覧 — ナレッジ追加すべき領域がわかる
  • ユニークユーザー数 — 実利用人数の把握
💡 改善サイクルが回る — 「答えられなかった質問」を見て不足ナレッジを特定 → 取り込み → 回答率が上がる、というループを数字で回せます。

📁 INGEST

5. ドラッグ&ドロップでナレッジ取り込み — 個人情報は自動マスキング

PDF・Excel・Word・PowerPoint などをドラッグするだけ。取り込み前に個人情報を自動検出してマスキングします。
  • 8 形式対応 — PDF / Excel / PowerPoint / Word / CSV / Markdown / テキスト / JSON
  • PII 自動検出 — 氏名・電話番号・メール・マイナンバー等を検知
  • リスク判定 — 「取り込み可 / 確認必要 / 非推奨」を自動で色分け
▲ 取り込み時に個人情報を検出し、マスキング要否を提示 (画面はデモデータ)
🌱 AUTO-FAQ

6. AI が「FAQ にすべき質問」を自動検出

同じテーマの質問が繰り返されると、AI が自動で「FAQ 候補」として抽出。ワンクリックでナレッジに昇格できます。
  • 自動クラスタリング — 似た質問をまとめて検出
  • 承認 / 編集 / 却下 — 候補をレビューしてナレッジ化
  • 自動承認モード — 信頼度が高い候補は自動でナレッジに追加する設定も可能
HOW TO

使い方 — 3 ステップ

1

ログイン

社内に共有された URL を開き、「Google でログイン」→ 会社の Google アカウントを選択。

2

質問する

画面下の入力欄に、知りたいことを日本語で入力して Enter。数秒で出典付きの回答が返ります。
例: 経費精算の締め切りは? VPN がつながらない時は?

3

活用する

回答に 👍 / 👎 でフィードバック。欲しい情報が無ければ「FAQ 追加リクエスト」。
管理機能では、統計分析や削減効果も確認できます。
