## ⚠ PoC 止まりで本番に出すには弱い箇所

### 1. LLM API がデモモード固定
**現状**：APIキー未設定の場合、Claude を呼ばずにスタブ応答（"ローカルモード"）
**必要**：
- 実 Anthropic API キーを取得
- 1日テスト → 月額の API コスト試算（35人で月¥1〜3万円見込み）
- Rate limit 対応（1分100リクエスト等）
**工数**：1日

### 2. 検索エンジンが TF-IDF（古い）
**現状**：`sklearn.TfidfVectorizer` の char_wb bigram。日本語の同義語に弱い
**問題例**：
- 「VPN繋がらない」と「VPN接続できない」が別文書扱い
- 「決済」と「精算」が結びつかない
**必要**：Embedding モデル（`multilingual-e5-large`）に切り替え
**工数**：1〜2日（ROADMAP Phase 1.1）
**効果**：検索精度 2〜3倍向上見込み

### 3. 認証が Google OAuth 設定待ち
**現状**：実装済みだが OAuth クライアントID 未取得 → DEMO_MODE で運用中
**必要**：
- Google Cloud Console で OAuth クライアント作成（10分）
- 許可ドメインの設定（例: `@example-edu.co.jp`）
- HTTPSデプロイ（コールバックURL要件）
**工数**：30分〜1時間

### 4. 永続化がファイルベース
**現状**：FAQ・監査ログ・フィードバックがファイル保存
**問題**：
- 複数サーバでスケールできない
- ロックの考慮が薄い
- バックアップが手動
**必要**：PostgreSQL 移行
**工数**：3〜5日

### 5. 単一テナント
**現状**：1サーバ = 1顧客の前提
**問題**：複数顧客を1サーバで運用できない
**必要**：マルチテナント化（テナントID 列追加 + データ分離）
**工数**：1〜2週間（ROADMAP Phase 3.1）

## 競合と比べてどう？

| 観点 | Inquira | ChatGPT Enterprise | NotionAI | Glean |
|---|---|---|---|---|
| 価格（35名/月） | ¥10万想定 | ¥21万 | ¥10〜15万 | ¥30万〜 |
| 業界特化 | ✅ プリセット式 | ❌ | ❌ | ❌ |
| データ主権 | ✅ 社内ホスト可 | △ Anthropic 依存 | ❌ Notion クラウド | △ 大手 |
| 既存資料活用 | ✅ PDF/Excel直接 | △ Notion経由 | △ Notion経由 | ✅ 全社検索 |
| 出典明示 | ✅ 必須 | △ オプション | △ | ✅ |
| ハルシネーション抑制 | ✅ 閾値+プロンプト | △ プロンプトのみ | △ | ✅ |
| 設置難易度 | 中（自社運用） | 低（SaaS） | 低（SaaS） | 高 |

**勝てる軸**：
1. **業界特化** — 教育・医療・金融プリセットを横展開
2. **データ主権** — 社内ホスト or ZDR で機密性をアピール
3. **既存資料が即使える** — Notion等への移行作業が不要

**負ける軸**：
- 設置の手軽さ（SaaSのワンクリック導入には勝てない）
- ブランド力（最初は「知らない会社」扱い）

→ 中堅企業の **「機密性は譲れない、SaaSベンダーは怖い」** セグメントを狙う戦略。
