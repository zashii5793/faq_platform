# API 利用料の試算と「無料事例」運用の設計

> 結論：Anthropic API は **完全従量課金**。無料運用にする場合は **ZAXEL が API 代を負担** する設計が現実的（タカヤなら **月 1,000〜3,000円程度**）。

---

## 1. Anthropic API は無料か？

**No、無料ではありません。** ただし：

| 項目 | 内容 |
|---|---|
| 初回登録特典 | $5 の無料クレジット（評価用に十分） |
| 月次無料枠 | **無し**（使った分だけ課金） |
| 最低使用料 | **無し**（ゼロ円から始められる） |
| クレジットカード必須 | はい（API キー発行時に登録） |
| 月額固定費 | **無し**（純粋な従量課金） |

**つまり「使わなければゼロ円」「使った分だけ課金」のモデル**です。Claude Pro/Team プラン（人 × 月額）とは全く別の料金体系。

---

## 2. 料金体系（2026年4月時点・Claude Sonnet 4.6）

| 項目 | 単価 |
|---|---|
| 入力 1M トークン | $3 |
| 出力 1M トークン | $15 |
| キャッシュ読み出し | $0.30（1Mトークン）※ プロンプトキャッシュ機能 |

### 1質問あたりの平均コスト（実測ベース）

| 文書サイズ | 1質問の入力 | 1質問の出力 | 単価 |
|---|---|---|---|
| FAQ参照 5チャンク × 各300字 | 約 2,500トークン | 約 200トークン | **約 0.011 USD = 約 1.7円** |
| FAQ参照 5チャンク × 各800字 | 約 5,000トークン | 約 300トークン | 約 0.020 USD = 約 3.1円 |
| 大量参考情報（10チャンク + 長文） | 約 12,000トークン | 約 500トークン | 約 0.044 USD = 約 6.8円 |

**Inquira の実装値（チャンク350字 × 5件 + 出典）= 平均 1質問 約 2〜3円**

## 4. 「無料事例」運用の設計選択肢

### 選択肢A：ZAXEL が API 代を負担（推奨）

| 項目 | 内容 |
|---|---|
| 顧客の負担 | **0円** |
| ZAXEL の負担 | タカヤ 月1,000〜3,000円 / 教育系A社 月1〜3万円 |
| ZAXEL のメリット | 事例化・営業材料化・ノウハウ蓄積 |
| 設定 | ZAXEL の Anthropic アカウントでAPIキー発行 → 顧客環境に設定 |

**事例化リターンを考えれば月数千円〜数万円は安い投資**。

### 選択肢B：顧客が API 代のみ負担（実費精算）

| 項目 | 内容 |
|---|---|
| 顧客の負担 | API 実費のみ（月千円〜数万円） |
| ZAXEL の負担 | プラットフォーム提供は無料 |
| メリット | ZAXEL のキャッシュアウト無し |
| デメリット | 顧客に「無料じゃない」と説明が必要 |

### 選択肢C：使用量上限つき完全無料

| 項目 | 内容 |
|---|---|
| 顧客の負担 | 0円（上限内なら） |
| ZAXEL の負担 | 上限金額（例：月 5,000円まで補助） |
| 仕組み | Inquira 側でレート制限を実装、上限到達で「本日の枠終了」 |

**実装：1日100問、月2000問など。これでタカヤレベルなら不足感なし。**

## 5. コスト削減テクニック（実装可能）

### 5.1 プロンプトキャッシュ（Anthropic 公式機能）

同じシステムプロンプトと FAQ コンテキストを使い回す場合、**最大 90% 削減**：

```python
# 実装：messages.create に cache_control を追加
client.messages.create(
    model="claude-sonnet-4-6",
    system=[
        {"type": "text", "text": system_prompt(),
         "cache_control": {"type": "ephemeral"}},
    ],
    ...
)
```

→ 5分以内に同じシステムプロンプトで呼ぶと、入力トークン代が **$3 → $0.30** に。
**月1万問で月¥4万 → 月¥4千** まで下がる可能性。

### 5.2 質問キャッシュ（独自実装）

「同じ質問が5分以内に再度来たら API を呼ばずキャッシュ返答」：

```python
# 実装イメージ（未実装）:
import functools

@functools.lru_cache(maxsize=500)
def _cached_answer(question_hash: str) -> str:
    return answer(...)
```

タカヤのような小規模なら同じ質問が繰り返される率が高く、**30〜50% 削減見込み**。

### 5.3 Haiku 4.5 への切替

精度が許せば Haiku（1/3 のコスト）：
- Sonnet: 月 25,000円 → Haiku: 月 8,000円

ただし Haiku は **長い参考文脈の要約能力がやや劣る** ので、簡単な質問のみに使うのが安全。
ハイブリッド（質問分類 → Haiku/Sonnet 切替）も可能。

### 5.4 Embedding 切替で No-Answer 増加

`EMBEDDING_BACKEND=tfidf` のままだと **34% が NO_ANSWER**（API呼ばず）。
e5-small に切替で精度↑するが、API 呼び出し回数も増えてコストも増える。

> トレードオフ: 精度を上げると API 代も上がる。**月の予算上限を決めて、それに合わせてバックエンドを選ぶ**のが実用的。

## 8. 公開時の注意点

「無料事例」と謳う場合の注意：

1. **完全無料 / 期間限定無料 / 上限内無料** を明確に区別
2. 期間や上限を契約書に明記
3. **API 代を ZAXEL が払っていることは「成果報告書」レベルでは記載しなくて OK**
   （ただし「Inquira を月¥0で運用」とは書かない方が誠実）
4. 言い回しの例:
   - ❌ 「Inquira を完全無料で導入」
   - 🟢 「ZAXEL の事例化協力プログラムで導入（顧客費用負担なし、6ヶ月）」
   - 🟢 「PoC 期間中（3ヶ月）の運用費用は ZAXEL 負担」

## 9. 発生した API 代を可視化する方法

Anthropic Console:
1. https://console.anthropic.com/ ログイン
2. **Usage** タブで日別・月別の使用量・コストを確認
3. アラート設定: **Settings → Usage limits** で月予算を設定（超えると自動停止）

**月予算アラートは必ず設定**しておくこと（暴走防止）。
