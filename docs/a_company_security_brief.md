## 1. システム構成と通信経路

```
┌─────────────────┐      HTTPS        ┌──────────────────────┐
│  A社ユーザー     │ ────────────────► │ Cloudflare Tunnel    │
│  ブラウザ        │                   │ (TLS終端・経路保護)   │
└─────────────────┘                   └──────────┬───────────┘
                                                 │ 暗号化
                                                 ▼
                                      ┌──────────────────────┐
                                      │ Inquiraサーバー       │
                                      │ (提供者のMac、ローカル)│
                                      └──────────┬───────────┘
                                                 │ HTTPS
                                                 ▼
                                      ┌──────────────────────┐
                                      │ Anthropic Claude API  │
                                      │ (米国・回答生成のみ)  │
                                      └──────────────────────┘
```

### 通信のセキュリティ

- **ブラウザ ↔ Cloudflare**: HTTPS（TLS 1.3）で暗号化。Cloudflare は世界的に利用されるCDN/トンネル事業者
- **Cloudflare ↔ Inquiraサーバー**: 同一トンネル内の暗号化通信。第三者からの傍受不可
- **Inquiraサーバー ↔ Anthropic**: HTTPS（TLS 1.2+）で暗号化

## 2. Anthropic API への送信内容（最重要）

### 何が送られるか

A社ユーザーが質問を投げた瞬間に、以下のデータが Anthropic Claude API へ送信されます:

1. **質問本文**（例: 「経費精算の手順を教えて」）
2. **検索結果の上位 5〜10 チャンク**（取り込んだ文書から、質問に関連する部分のテキスト）

### 送信されないもの

- ✘ A社ユーザーの個人情報（メールアドレス・氏名はサーバー内部のログのみ。Anthropic には送らない）
- ✘ 取り込んだ文書の **全文**（関連箇所のみ抽出して送信）
- ✘ 過去の質問履歴

### Anthropic 側の取り扱い（公式 Commercial Terms 準拠）

| 項目 | Anthropic の方針 |
|---|---|
| **モデル訓練への利用** | ❌ **行わない**（契約上保証） |
| **第三者への提供・販売** | ❌ 行わない |
| **保持期間** | ⚠️ **不正利用検出用に最大30日間**ログ保持 |
| **データ所在地** | ⚠️ **米国**のデータセンター |
| **人手によるレビュー** | ⚠️ 重大な不正利用が疑われる場合のみ、限定的に発生 |
| **削除依頼** | ✅ Anthropic Console から可能 |

**根拠**: Anthropic Commercial Terms of Service
> "Anthropic will not use Customer Content submitted via the API to train its models."

参考リンク:
- https://www.anthropic.com/legal/commercial-terms
- https://www.anthropic.com/legal/privacy

### A社にお願いしたいこと

- 機密性が高いと判断される文書（経営情報・個人情報を含むデータベース等）は、取り込み前にご相談ください
- 個人情報を含むファイル取り込み時は、後述の PII マスキング機能が自動で動作しますが、**最終確認は人手**で行うことを推奨します

## 3. データの保管場所と保持

### 提供者のサーバー（A社のデータが保管される場所）

| データ種別 | 保管場所 | 保持期間 |
|---|---|---|
| 取り込み済み文書（原本） | `data/raw/` | 試験期間終了まで |
| 取り込み済み文書（テキスト抽出後） | `data/faq_master/` | 試験期間終了まで |
| 検索インデックス | `data/embeddings.npz` 等 | 試験期間終了まで |
| 監査ログ（質問・利用履歴） | `data/audit/audit-YYYY-MM-DD.jsonl` | 試験期間終了 + 30日 |
| ユーザーセッション | メモリ上のみ | サーバー再起動で消去 |

### A社のデータが保管される範囲

- **提供者の Mac 1台のみ**（クラウド・外部ストレージへの自動アップロードなし）
- 試験期間終了後、A社の指示に応じて **全データを削除し、削除証跡をご提供**します
- 提供者は試験期間中、A社の事前承認なく取り込んだデータを他用途に転用しません

### バックアップ

- 試験期間中、提供者の判断で **日次でローカルバックアップ**を取得（外部送信なし）
- A社が削除を依頼した場合、バックアップも併せて消去

## 4. 個人情報・機密情報の取り扱い

### 自動 PII マスキング

文書取り込み時、以下のパターンを **自動検出して取り込み前に警告**します:

- 電話番号（携帯・固定）
- メールアドレス
- 社員番号らしき数字列
- 住所
- 銀行口座番号
- マイナンバーらしき番号
- 業界特化（医療系: カルテ番号、金融系: 口座番号等）

検出時は、取り込み画面で **「危険」「警告」判定**として表示し、ユーザーが該当箇所を **除外して取り込むか確認**できる UI を提供します。

### 制限事項

- PII マスキングは**完全ではありません**。複雑なフォーマット・氏名・自由記述内のセンシティブ情報は検出できない場合があります
- 取り込み判断は **A社の運用責任**でお願いします
- 一度取り込んだ文書も、管理画面から個別削除可能

## 5. アクセス制御

### 認証方式（本格運用時）

- **Google Workspace SSO** によるログイン必須
- ドメインホワイトリスト: `@a-company.co.jp` のメールアドレスのみ許可
- 個別メールホワイトリストも併用可（例: 一部の社外コンサルだけ追加で許可）

### 試験運用時の運用

- 試験期間中は **Cloudflare Tunnel の固定URL** を発行
- URL は試験参加者にのみ通知
- URL を知らない第三者からはアクセス不能
- 必要に応じて Cloudflare Access で **追加のメール認証ゲート** を設定可能

### ロール分離

- 一般ユーザー: 質問・回答閲覧のみ
- 管理者: 文書取り込み・削除・監査ログ閲覧（試験期間中は提供者が担当）

## 6. 監査ログ

すべての操作は監査ログに記録されます。

### 記録される項目

| イベント | 内容 |
|---|---|
| `query` | 誰が・いつ・何を質問したか・どの文書を参照したか |
| `query_error` | API エラー・キー失効等 |
| `ingest` | 誰が・いつ・どの文書を取り込んだか |
| `feedback` | 「役立った／要改善」の入力 |
| `faq_request` | FAQ 追加リクエスト |

### A社による監査

- 試験期間終了時、**監査ログ全件を JSONL 形式で A社に提供**します
- 期間中も、ご要望に応じて中間提出可能
- A社の社内コンプライアンス検証にお使いいただけます

## 7. A社のデータに対する権利

### 試験運用中

- ✅ **データ削除リクエスト**: メール1本でいつでも削除可
- ✅ **データ持ち出し**: 取り込んだ文書・ログをまとめてダウンロード可能
- ✅ **取り込み停止**: いつでも停止可能（事前通知不要）

### 試験運用終了時

提供者が以下を実施し、証跡を提供します:

1. すべての文書ファイルの削除（`data/raw/` と `data/faq_master/`）
2. インデックスファイルの削除（`data/embeddings.npz` 等）
3. 監査ログのアーカイブ提供と削除
4. バックアップの完全消去
5. **削除完了報告書**（実施日時・削除対象・確認方法）の提出

## 8. インシデント対応

### 万一のセキュリティインシデント発生時

提供者は以下の手順で対応します:

1. **インシデント検知から1時間以内**にサーバーを停止
2. **24時間以内**にA社へ第一報（メール・電話）
3. **72時間以内**に原因調査結果を文書で報告
4. データ流出があった場合、対象範囲と影響を明示

### 想定されるリスクと対策

| リスク | 影響度 | 対策 |
|---|---|---|
| Anthropic API キー流出 | 中（金銭被害） | Spend Limit 設定（月額上限）、キーは提供者のマシン外に出さない |
| サーバー侵入 | 大 | OS自動更新、SSH 鍵認証のみ、不要ポート閉鎖 |
| 取り込みデータの誤公開 | 大 | Cloudflare Tunnel URL を限定共有、Google SSO で本格認証 |
| Anthropic 側の障害 | 小 | API ダウン時は回答不可、データ流出には繋がらない |

## 9. 関連法令・規格

本システムは以下の枠組みを参照して運用します:

- **個人情報保護法**（日本）: 個人情報該当データの取り込み時は事前協議
- **GDPR**: A社が EU 個人を含むデータを扱う場合は別途協議（現状想定外）
- **Anthropic のセキュリティ認証**: SOC 2 Type II, ISO 27001 取得済み
  - https://trust.anthropic.com/
