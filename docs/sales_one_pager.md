# Inquira ／ 1ページサマリ（営業 / 紹介・初回商談用）

> 配布対象: 経営層・情シス部長・人事/総務マネージャ
> 配布形式: PDF 1〜2枚相当、または立ち話・電話商談での口頭ピッチに

---

## ⏱ 30秒ピッチ

> **社員からの「これってどうやるんでしたっけ？」を、AI が出典付きで自動回答。**
> 既存マニュアル（PDF・Excel・Word）をそのまま取り込むだけ。
> ChatGPT に機密情報を入れる「シャドウAI」リスクを根絶しつつ、
> 月¥3万から始められる中小企業向け SaaS です。

---

## 🎯 こんな会社・部門に効きます

- 従業員 **30〜500名規模** の中堅企業
- **情シス・総務・人事** に同じ質問が毎日繰り返される
- マニュアルが **PDF・Excel・Notion・チャット** に散在
- **新人教育** で先輩の時間が消える
- **ChatGPT を社員が個人利用** していて機密漏洩が不安
- **Google Workspace** を社員認証に使っている

---

## 💡 解決方法（仕組み）

```
社員が質問
  ↓
個人情報を自動マスキング
  ↓
社内ナレッジから関連箇所を検索（5チャンク）
  ↓
Claude AI が文書内容のみを根拠に回答
  ↓
出典＋確信度スコア付きで返答
```

**「学習」ではなく「参照」する設計** — 御社の文書は外部に焼き込まれません。

## ✨ 主要機能（中小企業の現場ニーズに直結）

| 機能 | 一言 |
|---|---|
| 🔍 自然言語 Q&A | チャット形式、出典必須、確信度スコア |

| 🔍 質問履歴検索 | 「先月のVPN関連質問は？」を即検索 |
| 🗂 CSV/JSONエクスポート | 月次報告書を Excel でそのまま編集 |
| ⚙ 組織情報編集 UI | 再起動なしで貴社名にカスタマイズ可能 |
| 📱 モバイル対応 | 現場担当者が iPhone で立ったまま使える |
| 🗄 バックアップ・復元 | ワンコマンドで data + .env を tar.gz 化 |
| 🔐 Google SSO | 社員 Workspace アカウントでのみログイン |
| 📋 監査ログ | 全操作を JSONL で記録（ISMS/Pマーク対応に） |
