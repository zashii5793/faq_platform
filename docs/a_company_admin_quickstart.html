QUICK START GUIDE

Inquira 管理者ご案内

宛先: A株式会社 ご担当者様
所要時間: 30 分 〜 1 時間
対象 URL: https://faq-a.inquira.app/
本サービスは SaaS 提供 のため、サーバー構築・API キー発行・認証設定はすべて弊社側で完了済みです。
御社にお願いするのは、既存マニュアル・FAQ のアップロードと社内告知のみ。その日から使い始められます。
1

ログイン

🔐 Google でログイン
https://faq-a.inquira.app/admin/upload にアクセスし、御社の Google アカウントでログインしてください。 管理者として登録済みのメールアドレスのみ管理画面が開きます。
2

マニュアルを投入

📁 ドラッグ＆ドロップ
「📁 ファイル取り込み」タブにマニュアル・FAQ・規程類をドラッグ。 PII（個人情報）は自動検出・マスキングされます。 推奨は 人事 → 情シス → 業務マニュアル の順。
3

確定 → 社内告知

🚀 取り込み確定
画面下部の「取り込み確定」を押すと検索インデックスに反映され、即時利用可能になります。 最後に https://faq-a.inquira.app/ を社内に共有してください。

📌 Inquira でできること

  • 社内マニュアルを AI が代理で回答（出典付き）
  • 未解決の質問は管理者に自動エスカレ
  • 解決した会話から FAQ 候補を自動生成（🌱 タブ）
  • 削減した工数・コストをリアルタイム可視化（📈 タブ）

📂 取り込み可能な形式

PDF Excel (.xlsx) PowerPoint (.pptx) Word 由来テキスト CSV Markdown テキスト (.txt) JSON

📅 導入後の運用（管理者の所要時間）

毎週 15分: 「🌱 FAQ 候補」タブで、AI が見つけた候補質問を承認 / 編集 / 却下 毎月 5分: 「📈 削減効果」タブで削減時間・コストを確認 → 経営層に共有
Inquira ご担当 ／ サポート窓口
