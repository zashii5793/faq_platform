## 方針

「暗い」は**配色**と**文章のトーン**の両方に効いていると判断し、両方を扱いました。

- **配色**: 黒背景＋薄グレー文字 → 生成り `#FDF8F1` ／ 白 ／ 淡い青 `#EAF2FC` を基調に、
  オレンジ `#F0910A` とブルー `#0B6BCB` をアクセントに配置。本文コントラスト比は 12:1 以上を確保
- **文章**: 課題・危機感を主語にした書き出しから、強み（昭和40年創業・鈑金塗装まで自社完結・無料代車・
  引取納車・ワンストップ）を主語にした書き出しへ。締めは読者への招待で終える
- **経営理念は改変しない**。3項目の意味と順序は維持し、一言見出しを付けて可読性だけを上げる

## 判明した重要事項（2026-08-08 保存ページ受領後）

### 1. サイトは **Google サイト（新版）** だった

フッターに `Google サイト` 表記。**CSS の差し替えはできません。** 見た目を変える手段は
「テーマ／バナー設定」と「埋め込み（コードを埋め込む）」の2つのみ。
→ 対処手順を `google-sites-settings.md` に分離しました。

### 2. 「暗い」の正体は実測できた

現行サイトから抽出した実際の色：

| 色 | 使用箇所 | 出現数 |
|---|---|---|
| `#000000` | 各ページ上部のバナー帯 | 11 |
| `#333333` | Read More ボタン、ロータスクラブの帯 | 24 |
| `#ff0000` / `#fa3019` / `#cc4125` | サービス概要の説明文、ブログ誘導文、SNS 文 | 6 |

加えてトップの**夕景（逆光）ヒーロー画像**が上部を占め、暗さを強めています。

### 3. 経営理念の原文を逐語で確認できた

東京海上リペアネットの工場ページに全文掲載あり。`copy-draft.md` に記載。

### 4. 採用ページの年数表記が古い

「来年には創業60年」＝2024年頃の記述。昭和40年創業なので**2025年に60周年、2026年現在は61年目**。要修正。

## 🚩 至急のご確認事項

**自社HP上に第三者の広告（Criteo 等）が表示されています。** 埋め込まれたブログで Blogger の
広告表示機能が ON になっているためで、競合他社の広告が出る可能性があります。
Blogger の「収益」→「ブログに広告を表示する」を OFF にすれば止まります。詳細は `blog-migration.md`。
