# ブログのHP移行：現状分析と方針案

案件ID: 20260808-takaya-hp-fix ｜ 作成: 2026-08-08 ｜ **下書き（未承認）**

ご依頼「ブログデータはHPに移行したいな」に対する調査結果です。
保存いただいたトップページの .mhtml に**ブログの埋め込みフレームが丸ごと含まれていた**ため、
ブログ本体へ接続できない環境でも中身を確認できました。

---

## 1. 前提が違っていました：**ブログは既にHPに埋め込まれています**

トップページの下部、「おクルマに関する、あらゆる”いい情報”を↓ブログに定期的に書いています。」の下に、
`takayagroup.blogspot.com` を **iframe で埋め込んだブロック**が既に存在します。

スクリーンショット（`preview/real-top.png`）でこの部分が**大きな空白**に見えていたのは、
保存ページからの再現時に外部読み込みが走らなかったためで、実際のサイトではブログが表示されています。

つまりご要望の「移行」は、**ゼロから載せる作業ではなく、「今の載り方を作り直す」作業**になります。

---

## 2. 【要対応】自社HP上に他社の広告が表示されています

これが今回の調査で見つかった**一番優先度の高い問題**です。

埋め込まれたブログのHTMLに、次の記述が含まれています。

```html
<ins class="adsbygoogle" data-ad-client="ca-pub-..." data-ad-host="pub-..." data-ad-format="horizontal">
```

`data-ad-host` が入っているのは、**Blogger の「収益」機能（広告表示）がONになっている**状態です。
保存ページには実際に **Criteo / DoubleClick の広告フレーム**が一緒に記録されていました。

### 何が起きているか

> お客様が **takayagroup.co.jp を見ると、ページ内に第三者の広告が表示される**

広告の中身は閲覧者ごとに自動で変わるため、**競合他社（他の中古車店・車検チェーン等）の広告が
自社サイト上に出る可能性**があります。企業サイトとしては避けたい状態です。

### 対処（すぐできます）

1. Blogger にログイン → 対象ブログを選択
2. 左メニュー **「収益」** → **「ブログに広告を表示する」を OFF**
3. あわせて **「レイアウト」→ 広告ガジェットがあれば削除**

収益額はおそらくごくわずかのはずです。**企業サイトの信頼性と引き換えにする価値はありません。**

## 4. 本当の問題：**161本の資産が自社ドメインに一切効いていない**

記事は `takayagroup.blogspot.com` にあります。
検索エンジンから見ると、これらの記事の評価は**すべて blogspot.com 側に溜まります**。

> **161本の良質な記事を書いても、`takayagroup.co.jp` の検索順位には貢献していない**

「岡山 車検」「岡山 中古車」で自社サイトを見つけてもらいたいなら、ここが最大の機会損失です。

さらに、埋め込み（iframe）内のコンテンツは**検索エンジンに親ページの内容として扱われません**。
今の「HPに埋め込む」形では、この問題は解決しません。

---

## 5. 方針案

### ⚠️ まず前提：Google サイトにブログ機能はありません

「全記事をHPへ移す」＝ **1記事＝1サブページを手作業で161回**。
記事一覧・カテゴリ・新着順の自動表示も無いため、**追加するたびに手で並べ替え**が必要です。
現実的ではありません。正直にお伝えします。

### 案A：広告を止めて、埋め込みの見せ方を整える（最小・即日）

| | |
|---|---|
| やること | ①Blogger の広告OFF ②テンプレート整理（テンプレ切替UIを隠す）③埋め込み枠の高さ・位置調整 ④トップの赤文字リンクをカード型ボタンに |
| 工数 | 半日程度 |
| 効果 | 広告問題が消え、見た目が整う |
| 残る課題 | **SEO の資産は blogspot のまま**（本質は未解決） |

### 案B：主要記事だけHPのコンテンツページに作り直す（中間・推奨）

| | |
|---|---|
| やること | 営業に効く記事を **10〜20本厳選**し、Google サイトの通常ページとして書き直す（例：「車検の豆知識」「洗車とコーティング」「リースの損得」）。元記事からは新ページへリンク |
| 工数 | 1本あたり0.5〜1時間 × 10〜20本 |
| 効果 | **自社ドメインに検索評価が溜まり始める。**「岡山 車検」等での露出が狙える |
| 残る課題 | 日々の更新は引き続き Blogger |

> **これを推奨します。** 161本すべてではなく、**効く記事だけ自社ドメインに移す**のが費用対効果で最良です。

### 案C：ブログ基盤ごと自社ドメインへ移す（最大・別案件）

| | |
|---|---|
| やること | WordPress 等を `blog.takaya-gp.jp` などに構築し、161本をインポート。旧URLから301リダイレクト |
| 工数 | 構築・移行・確認で数日〜。サーバー費用も発生 |
| 効果 | **161本の資産が完全に自社のものになる。** 更新も自社ドメインに積み上がる |
| 注意 | Google サイトとは別基盤になるため、HP本体との住み分け設計が必要。**本件とは別案件として見積もるべき規模**です |
