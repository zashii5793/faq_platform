# 整備保証規定

## タカヤモーター 整備保証の基本

整備作業に対して以下の保証を提供しています。

| 整備内容 | 保証期間 | 走行距離上限 |
|---|---|---|
| エンジン分解整備 | 6ヶ月 | 10,000km |
| ミッション分解整備 | 6ヶ月 | 10,000km |
| ブレーキ整備 | 3ヶ月 | 5,000km |
| 電装系修理 | 3ヶ月 | 5,000km |
| 一般整備（オイル交換等） | 1ヶ月 | 1,000km |
| 板金塗装 | 12ヶ月 | 走行距離不問 |

期間と距離は **どちらか早く到達した時点** で終了。

## 保証適用外

- お客様の運転による事故・破損
- 改造による不具合
- 経年劣化・自然消耗
- 他社で再整備された場合
- 保証書を紛失した場合（再発行不可）

## 保証対応の流れ

1. 受付で保証書（紙またはアプリ）を確認
2. 「タカヤCarEdit」で整備履歴を照合
3. 該当作業に起因する不具合と判定 → 無償対応
4. 該当しない場合 → 通常の有償整備として見積もり

## クレーム対応

クレームが発生した場合は **必ず所長へエスカレ**。
独断対応は禁止。録音許可をいただいた上で経緯を記録。

## 関連書類の保管

- 整備記録: 法定保管 5年（業務システム + 紙原本）
- 保証書控え: 7年保管（経理保管庫）
